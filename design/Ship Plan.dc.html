1 · Collect sign-ins in a database

Supabase recommended
Postgres + Auth (Apple, Google, email). Row-level security, free tier. SQL is in supabase/schema.sql.
Firebase Auth + Firestore
Same providers, NoSQL. Good if you want Google tooling; harder to query sign-in history.
profilesOne row per user, created automatically on sign-up (home country, crypto toggle)
sign_in_eventsEvery sign-in: provider, platform, time
broker_linksWhich broker is linked (label only)
watchlistSaved vendors / markets

Upstox tokens stay on the phone (Keychain / Keystore) and are never written to the database, the same rule as the repo's README.

2 · Fork and install from the README

curl -fsSL https://raw.githubusercontent.com/aromal-a/Quant-BETA-convulsions-/main/install.sh | bash
  1. Add repo-additions/install.sh to the repo root as install.sh. It checks git + Python 3.9, clones (or updates), then runs your existing setup.sh.
  2. Paste README-install-section.md into the README above "Quick start".
  3. Fork users pass REPO=<you>/Quant-BETA-convulsions- to install their own copy.

3 · Release on the App Store and Google Play

The repo has no mobile app yet (Python + a static web page), so the first decision is how to build it.

A · Expo (React Native) + EAS
recommended
One codebase in mobile/ for both stores. eas build makes the iOS and Android binaries in the cloud (no Mac needed) and eas submit uploads them. Supabase and Apple/Google sign-in have Expo libraries. The beam canvas ports to react-native-skia.
B · Capacitor wrapping docs/
fastest, risky on iOS
Reuses the existing web page. Apple often rejects apps that are mostly a website (guideline 4.2), so you'd need native features such as sign-in, a watchlist and notifications.
C · PWA, plus a Play Store TWA
cheapest
Make docs/ installable ("Add to Home Screen"). Google Play accepts it as a Trusted Web Activity (Bubblewrap). Not on the App Store.
D · Native Swift + Kotlin
best feel, 2× work
Two apps to build and maintain. Only worth it if you need deep platform features.
App Store checklist
  • Apple Developer Program, $99/year
  • If you offer Google sign-in, you must offer Sign in with Apple too
  • In-app account deletion
  • Privacy policy URL + privacy "nutrition" labels
  • TestFlight beta → App Review
  • Keep the "paper money only, not financial advice" wording visible
Google Play checklist
  • Play Console, $25 one-time
  • New personal accounts: closed test with 12+ testers for 14 days before production
  • Account deletion: in the app and through a web link
  • Data safety form + privacy policy
  • Financial features declaration
  • Upload an .aab (EAS builds it)

Store rules and fees change; check them in App Store Connect and the Play Console before you submit.
